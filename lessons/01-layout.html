Lesson 01

From Boxes to Layout

You already know how to create HTML elements and style them using CSS. Now we are going to learn how to control how those elements are arranged on the page.

What you will learn

By the end of this lesson you should be able to:

  • create a simple HTML and CSS project in Visual Studio Code
  • explain normal document flow
  • identify a flex container
  • identify flex items
  • use display: flex
  • create space between items using gap
  • make flex items share the available space

Before you start

We are going to build a small website throughout these lessons. Start by creating a new project in Visual Studio Code.

Set up your project

  1. Open Visual Studio Code.
  2. Create a new folder called web-design-project.
  3. Open this folder in Visual Studio Code.
  4. Create a new file called index.html.
  5. Type ! and press Enter.

Visual Studio Code uses Emmet to generate the basic HTML structure for you.

Your page should now look similar to this:

HTML 
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>

<body>

</body>

</html>

Make two small changes

Change the page title from:

HTML 
<title>Document</title>

to:

HTML 
<title>Learn Web Design</title>

Then add this heading inside the <body>:

HTML 
<h1>Learn Web Design</h1>

Check

Save the file and open it in your browser. Can you see the heading?

1. Create your stylesheet

We also need a CSS file for the styles we are going to add.

Your turn

  1. Create a new file called style.css.
  2. Save it in the same folder as index.html.

Your project should now look like this:

web-design-project/
│
├── index.html
└── style.css

Next, link the stylesheet to your HTML page by adding this inside the <head>:

HTML 
<link rel="stylesheet" href="style.css">

Think

What would happen if the file was called styles.css but the HTML still said style.css?

2. Remember the box model?

Every HTML element creates a box.

You have already worked with the parts of that box: content, padding, border and margin.

Think

If we create three <article> elements, where do you think they will appear by default?

3. Create three cards

We are going to create three cards representing the three core technologies used on the web.

Add the following code underneath your <h1>.

HTML 
<section class="cards">

    <article class="card">
        <h2>HTML</h2>
        <p>HTML provides the structure and content of a webpage.</p>
    </article>

    <article class="card">
        <h2>CSS</h2>
        <p>CSS controls the appearance and layout of a webpage.</p>
    </article>

    <article class="card">
        <h2>JavaScript</h2>
        <p>JavaScript adds behaviour and interaction.</p>
    </article>

</section>

Your turn

Add the cards to your page, save the file and refresh the browser.

Check your HTML

Which element contains all three cards?

Which class is shared by every card?

4. Style the cards

Open style.css and add the following rule.

CSS 
.card {
    border: 2px solid #333;
    padding: 20px;
    margin-bottom: 20px;
}

Your turn

Save the CSS file and refresh the browser.

You should now be able to see the box around each card.

Box model check

Which property creates space inside the card?

Which property creates space outside the card?

5. Why are the cards stacked?

The cards still appear one underneath another.

This is normal.

Block-level elements usually take up the available width and appear one underneath another. This is part of normal document flow.

Experiment

Add this property to your .card rule:

CSS 
width: 200px;

Save and refresh the browser.

Did making the cards narrower make them move next to each other?

What should you notice?

The cards become narrower, but they still appear one underneath another.

Changing the size of a box does not automatically create a layout.

6. Introducing Flexbox

We want the three cards to appear next to each other.

Instead of changing the individual cards, we can change how their parent element arranges them.

Remove the temporary width: 200px; from your card rule.

Then add this new rule:

CSS 
.cards {
    display: flex;
}

Your turn

Save your stylesheet and refresh the browser.

What changed?

New terminology

The element with display: flex is called the flex container.

Its direct children become flex items.

Check your understanding

In our example, which element is the flex container?

Which elements are the flex items?

7. Add space between the cards

The cards are now sitting next to each other, but they need some space between them.

Add gap to the flex container.

CSS 
.cards {
    display: flex;
    gap: 20px;
}

Check your understanding

What does gap control?

A. The space inside each card
B. The space between the cards
C. The width of each card

Show answer

B. The gap property creates space between the flex items.

8. Make the cards equal width

At the moment, the cards may not all be the same width.

Add this property to your existing .card rule:

CSS 
flex: 1;

Your finished rule should now look like this:

CSS 
.card {
    border: 2px solid #333;
    padding: 20px;
    margin-bottom: 20px;
    flex: 1;
}

Each card now takes an equal share of the available space.

Experiment

Temporarily remove flex: 1;.

What happens to the widths of the cards?

9. Challenge

Add a fourth card

Without copying a finished solution, add another card for GitHub.

Your cards should now represent:

  • HTML
  • CSS
  • JavaScript
  • GitHub

Make sure all four cards:

  • appear in one row
  • have space between them
  • share the available space equally
Hint

The new GitHub card should be another <article class="card"> inside the existing <section class="cards">.

Show CSS solution
CSS 
.cards {
    display: flex;
    gap: 20px;
}

.card {
    border: 2px solid #333;
    padding: 20px;
    margin-bottom: 20px;
    flex: 1;
}

10. What have you learned?

In this lesson you started with a normal HTML page and turned a group of stacked elements into a layout.

You have used:

  • semantic HTML
  • classes
  • the box model
  • normal document flow
  • display: flex
  • gap
  • flex: 1

Final check

Why did we add display: flex to .cards rather than to each individual .card?
