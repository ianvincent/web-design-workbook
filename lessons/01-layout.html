Lesson 01

From Boxes to Layout

You already know how to create HTML elements and style them using CSS. Now we are going to learn how to control where those elements appear on the page.

What you will learn

By the end of this lesson you should be able to:

  • explain normal document flow
  • identify a flex container
  • identify flex items
  • use display: flex
  • create space between items using gap

1. Remember the box model?

Every HTML element creates a box.

You have already worked with the parts of that box: content, padding, border and margin.

Think

If we create three <article> elements, where will they appear by default?

2. Create three cards

We are going to create three cards representing the three core technologies used on the web.

HTML 
<section class="cards">

    <article class="card">
        <h2>HTML</h2>
        <p>HTML provides the structure of a webpage.</p>
    </article>

    <article class="card">
        <h2>CSS</h2>
        <p>CSS controls the appearance and layout of a webpage.</p>
    </article>

    <article class="card">
        <h2>JavaScript</h2>
        <p>JavaScript adds behaviour and interaction.</p>
    </article>

</section>

Your turn

Add this section to your webpage.

Save the file and view it in your browser.

3. Style the cards

Add the following CSS.

CSS 
.card {
    border: 2px solid #333;
    padding: 20px;
    margin-bottom: 20px;
}

Question

Why do the cards still appear one underneath another?

4. Normal document flow

By default, block elements normally appear one underneath another.

Making an element narrower does not automatically make another element move alongside it.

Experiment

Add this property to the card:

CSS 
width: 200px;

What happens?

5. Introducing Flexbox

We want the three cards to appear next to each other.

To do this, we can turn their parent element into a flex container.

CSS 
.cards {
    display: flex;
}

Your turn

Add this rule to your stylesheet and refresh the browser.

What changed?

New terminology

The element with display: flex is called the flex container.

Its direct children become flex items.

6. Add space between the cards

The cards are now sitting next to each other, but they need some breathing room.

CSS 
.cards {
    display: flex;
    gap: 20px;
}

Check your understanding

What does gap control?

A. The space inside each card
B. The space between the cards
C. The width of each card

Show answer

B. The gap property controls the space between flex items.

7. Make the cards equal width

Add this rule:

CSS 
.card {
    flex: 1;
}

Each card will now take an equal share of the available space.

Challenge

Can you build it?

Without copying another example, try to create four cards representing:

  • HTML
  • CSS
  • JavaScript
  • GitHub

Make them appear in one row with space between them.

Hint

Remember: the parent element needs to become the flex container.

Show solution
CSS 
.cards {
    display: flex;
    gap: 20px;
}

.card {
    flex: 1;
}
